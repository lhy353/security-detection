# Art Paper Size Guide

## Purpose

Use this prompt-only skill when artists, students, parents, teachers, or studio users waste paper by choosing the wrong size, medium, or storage spot for a project. The deliverable is a printable studio paper size and use guide that combines paper inventory, project fit, medium compatibility, trimming notes, and storage dimensions in one visible wall card.

This skill covers ordinary paper selection and studio organization only. It may include a basic reminder to use good ventilation with strong-smelling or wet media, but it does not provide hazardous material guidance, chemical handling instructions, disposal directions, protective equipment advice, or professional studio safety analysis.

## Safety Boundary

Keep safety notes basic and non-technical:

- Use good ventilation when working with strong-smelling or wet media.
- Follow product labels and classroom or studio rules.
- Keep messy media away from food, pets, and small children as appropriate.

Do not provide hazardous material advice, chemical mixing guidance, solvent handling, dust control procedures, disposal instructions, protective equipment selection, medical advice, or emergency guidance. If the user asks about hazardous materials, say this skill only creates a basic paper size guide and they should follow product labels and appropriate studio or school rules.

## Core Principles

- Match paper size to the finished project before cutting.
- Record both common names and actual dimensions when known.
- Note medium fit in practical terms: dry drawing, markers, watercolor, gouache, acrylic sketching, collage, printmaking practice, or mixed media.
- Add storage location and maximum sheet size so paper does not get bent.
- Include trim yield notes to reduce waste.
- Keep the final guide clear enough for a studio wall, classroom cart, family art shelf, or supply closet.

## Required Inputs

Ask for practical paper details:

- Paper sizes on hand, using names or dimensions.
- Paper type or weight, if known: sketch, drawing, watercolor, Bristol, mixed media, newsprint, printmaking, cardstock, or construction paper.
- Common projects: thumbnails, greeting cards, studies, posters, portfolios, mats, prints, comics, class projects, or kids crafts.
- Media usually used on the paper.
- Storage spaces: drawer, flat file, shelf, tube, portfolio, bin, cart, folder, or drying rack.
- Whether the guide should include trim yield notes.
- Preferred output style: wall chart, supply closet card, classroom cart guide, family art shelf label, or one-page printable.

Do not ask for chemical inventories, hazardous material procedures, health information, or emergency scenarios.

## Workflow

1. **Inventory paper.** List sizes, paper types, approximate counts, and storage spots.
2. **Map common projects.** Rank the user's most common art or school projects.
3. **Match size to use.** Pair each project with a best-fit paper size and backup size.
4. **Note medium fit.** Add practical compatibility notes based on the paper type and user-provided media.
5. **Add trim yield.** Show simple cut-down options, such as one large sheet to two half sheets or four quarter sheets.
6. **Add storage dimensions.** Note where sheets fit flat and where they should not be forced.
7. **Add basic ventilation line.** Include only a simple reminder for strong-smelling or wet media.
8. **Create printable guide.** Format the guide as a wall card, drawer label, cart card, or one-page studio reference.

## Output Format

Return an art paper size guide with these sections:

1. **Studio Snapshot**
   - Studio, classroom, or storage area
   - Main users or neutral role
   - Common project types
   - Storage style
2. **Paper Inventory Table**
   - Paper name or size
   - Actual dimensions if known
   - Paper type or weight if known
   - Approximate count
   - Storage location
   - Status: stocked, low, oversized, needs sorting, or unknown
3. **Project Fit Guide**
   - Project type
   - Recommended size
   - Backup size
   - Trim note
   - Waste-reduction tip
4. **Medium Compatibility Notes**
   - Paper type
   - Works well for
   - Use with caution for
   - Avoid for
   - Basic note: use good ventilation with strong-smelling or wet media and follow labels
5. **Storage and Handling Map**
   - Flat storage spot
   - Rolled or tube storage, if used
   - Portfolio or travel storage
   - Maximum sheet size for each storage area
   - Bend or crease risk note
6. **One-Page Printable Wall Card**
   - Top five paper sizes
   - Best uses
   - Storage locations
   - Trim yield shortcuts
   - Basic ventilation reminder

## Example Prompts

- "I have a stack of mixed paper in my studio and I keep grabbing the wrong size. Build me a printable paper size guide with project fit, medium notes, and storage locations."
- "I teach an art class and need a wall card showing which paper sizes work best for watercolor, charcoal, and collage so students stop wasting sheets."
- "I'm organizing a family art shelf with sketch paper, cardstock, and newsprint. Create a simple paper inventory guide with trim yield notes and a basic ventilation reminder."

## Quality Bar

A strong result helps users pick the right sheet before starting, reduce waste, and store paper without bending it. It should combine size, medium, project, and storage information while keeping safety language limited to a basic ventilation and label-following reminder.
