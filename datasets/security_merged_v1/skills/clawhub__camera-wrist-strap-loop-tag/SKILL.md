# Camera Wrist Strap Loop Tag

## Purpose

Use this prompt-only skill when camera gear packing misses lead to forgotten batteries, empty memory cards, or missing straps right before a trip or shoot. The deliverable is a set of tiny loop tags that attach to a camera wrist strap or bag with pack, charge, and return visual cues.

The tag is about physical packing prompts only. It should not include security advice, tracking recommendations, access control tips, gear lock instructions, or any content related to preventing theft or unauthorized access.

## Safety Boundary

Do not request, reveal, or print security advice, anti-theft tips, tracking device recommendations, lock instructions, access control guidance, gear serial numbers, GPS tracker suggestions, or any content related to physical security or unauthorized access prevention.

Do not print location data, travel itineraries, shoot addresses, hotel names, or any information that could reveal where gear will be or where it is stored. This tag is a simple pre-trip prompt, not a security document.

## Core Principles

- Use short cue words that fit on a tiny loop tag attached to a wrist strap.
- Cover the three essential pre-trip checks: pack, charge, return.
- Include simple check mark spaces for visual confirmation.
- Keep the tag small enough to loop onto a wrist strap, camera bag zipper, or gear case.
- Use generic language that works for any camera type without brand specifics.
- Keep the finished tag printable, durable with tape or lamination, and replaceable.

## Required Inputs

Ask for practical packing routine details only:

- Trip type: day shoot, weekend trip, event coverage, travel, studio session, or casual outing.
- Gear pieces to remember: camera body, lens, battery, memory card, strap, lens cap, charger, or bag.
- Preferred cue words: "pack," "charge," "return," "check," "done," or custom short words.
- Tag attachment point: wrist strap loop, camera bag zipper, gear case handle, or key ring.
- Preferred tag size: tiny loop tag, small zipper tag, medium bag tag, or one-page multi-tag printable.

Do not ask for camera serial numbers, gear value, insurance details, travel dates, shoot locations, hotel names, safe codes, lock combinations, tracking preferences, or security setup information.

## Workflow

1. **Pick trip use case.** Identify the type of shoot or trip that needs a packing prompt.
2. **Choose cue words.** Select short, scannable words for pack, charge, and return reminders.
3. **Size tag.** Determine the tag dimensions based on the attachment point.
4. **Add check marks.** Include check boxes or dot spaces for visual confirmation before leaving.
5. **Print and attach.** Produce the tag and attach it to the wrist strap loop, bag, or gear case.
6. **Add safety guard.** Confirm no security, tracking, location, or access content appears on the tag.
7. **Produce the printable tag.** Format clean loop tags with pack, charge, and return cues.

## Output Format

Return a camera wrist strap loop tag set with these sections:

1. **Trip Use Case Card**
   - Trip or shoot type
   - Gear pieces to remember
   - Attachment point
   - Cue words selected
2. **Loop Tag Design**
   - Front: primary cue word such as "PACK," "CHARGE," or "RETURN"
   - Back or side: check mark boxes for each gear piece
   - Small arrow or icon for quick visual scan
3. **Check Mark Space**
   - Gear item name in tiny text
   - Open box or circle for marking
   - Space for three to five items maximum
4. **Attachment Guide**
   - How to loop the tag onto a wrist strap
   - How to attach to a bag zipper or gear case
   - When to replace the tag for a new trip
5. **Print Layout**
   - Multi-tag page with cut lines
   - Size options for different attachment points
   - Durable use note: laminate or cover with clear tape

## Quality Bar

A strong result gives a quick visual packing prompt without any security, tracking, location, or access content. It should feel like a tiny travel helper: simple words, check boxes, small size, and clear attachment guidance.
