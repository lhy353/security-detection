# 证券行业公允价值变动分析技能使用指南

## 功能说明
针对上市券商年报中的公允价值变动相关数据进行结构化提取与分析，重点关注金融资产浮盈浮亏情况、各业务板块贡献，快速输出标准化分析结果，自动保存为markdown格式的分析报告。

## 分析维度
自动输出3个核心模块内容，所有数据均来自年报利润表、资产负债表及财务附注中「公允价值变动收益」「金融资产公允价值变动」相关披露：
1. 📊 公允价值变动总体情况表（总额、同比变动、增速、占归母净利润比例）
2. 📈 不同类别金融资产公允价值变动贡献表
3. 🧾 结构化业务分析解读（变动原因、业务特征、风险提示）

## 使用流程
1. 接收用户上传的券商年报PDF文件
2. 执行PDF文本提取：`pdftotext [pdf路径] /tmp/fairvalue_report.txt`
3. 运行分析脚本：`python3 {baseDir}/scripts/analyze_fairvalue.py /tmp/fairvalue_report.txt [可选：输出文件路径]`
4. 自动完成：数据提取、表格生成、业务解读、结果本地保存

## 输出规范
1. 控制台直接输出完整分析结果
2. 自动保存为markdown格式文件，默认路径：`./fair_value_analysis.md`，支持自定义输出路径
3. 金额单位统一为「亿元」，百分比保留2位小数，同比增速保留2位小数并标注正负符号
