# Skill mirror (GitHub-portable)

Generated by:

```bash
python scripts/build_skill_mirror.py
```

Each entry is `datasets/skill_mirror/<safe_id>/SKILL.md` (+ `meta.json`).
Commit this directory when you want clones / GitHub downloads to include skill text
without depending on `E:\clawhub_datasets` or `external/MalSkillBench-main`.

By default the repo `.gitignore` ignores mirrored files so the working tree stays light;
remove the ignore rules (or force-add) before publishing the mirror.
